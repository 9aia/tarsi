pub fn dispatch(req: &Request, env: Env<'_>) -> Response
Expand description

Dispatch one parsed pavo wire pavo_protocol::wire::Request to its response. env feeds the tarsi-serve lookup ($TARSI_SERVE override) — injectable so tests never touch the process env.

Read-only by construction: the only serve ops reachable are manifest/profiles/plan/changelog; release is never dispatched. render/submit/jobs/notifications answer ok:false — the manifest claims none of them.
