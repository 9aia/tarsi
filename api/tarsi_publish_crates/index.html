tarsi-publish-crates — crates.io publisher. Runs cargo publish --manifest-path <unit>/Cargo.toml per unit; the caller supplies units already in dependency order (plan_release topo-sorts). Retries crates.io 429/rate-limit responses with exponential backoff + jitter, honoring a server Retry-After hint when cargo surfaces one; each attempt is bounded by a wall-clock timeout (verify builds on heavy crates can run for minutes — I-003). “Already exists” counts as success (idempotent re-runs).

CARGO_TOKEN_ENV
The env var cargo reads for the default-registry token — a resolved token is always injected under this name regardless of which token_env fallback supplied it.
DEFAULT_RETRY_BASE
Default base delay for 429 retries — doubles per attempt up to DEFAULT_RETRY_MAX. crates.io asks bulk publishers to slow down by minutes, not seconds.
DEFAULT_RETRY_MAX
Default ceiling for computed 429 backoff. A server Retry-After hint is honored verbatim and may exceed this.
DEFAULT_TIMEOUT
Default per-attempt wall-clock cap for cargo publish — covers the package verify build plus upload on heavy crates (tamias-serve/tamias-tui exceeded shorter limits, I-003).
