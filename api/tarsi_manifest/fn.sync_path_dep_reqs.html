pub fn sync_path_dep_reqs(root: &Path) -> Result<bool, ManifestError>
Expand description

Rewrite version reqs on path deps so each names the target package’s current manifest version. cargo publish ships path deps with their version req — after a bump the req must match the new version (^0.1.5 rejects 0.2.0, and cargo’s own resolver fails the same way on cargo check). Run after write_unit_version writes land. Covers [workspace.dependencies] in the root manifest plus dependencies/build-dependencies/dev-dependencies in every workspace member; only entries carrying both path and a string version are touched. Returns true when any file changed.
