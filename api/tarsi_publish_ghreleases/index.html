tarsi-publish-ghreleases — GitHub Releases publisher. Creates a release per unit tag with the rendered notes as the body, then uploads the job’s PublishAssets to the release’s upload_url (the two-step flow: POST /repos/{o}/{r}/releases → POST {upload_url}?name=<file> with the binary body).

Idempotent re-runs: the release is looked up by tag first (GET /repos/{o}/{r}/releases/tags/{tag}) and reused when it exists; an asset whose name is already attached is DELETEd and re-uploaded — replace semantics, latest build wins. Blocking ureq per the bupha-github convention; the token comes from the TokenResolver — token_ref (a cuora:// secret ref) first, then the env var named token_env — the value never appears in config, logs, or args.
