cargo xtask pack — stage the tamias pack payloads (T-014 + PL-014 D3): release-build tarsi-serve into libraries/tarsi/tools/bin/<host-triple>/ (the payload-bin dir tamias install links onto PATH) and tamias-driver-tarsi into libraries/9aia-release/drivers/bin/<host-triple>/ (the bundled-driver dir tamias registers before dispatching the type: tarsi install — the pack self-provisions its driver). Gitignored on purpose: binaries are build artifacts; the committed packs are just manifests + this staging verb.
