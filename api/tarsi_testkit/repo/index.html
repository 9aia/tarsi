Real-git fixture repos for VCS-touching tests — temp workspaces with conventional commits, tags, and a bare origin, built with the git CLI (no VCS-impl dependency, so any [lasius_vcs::Vcs] adapter can be pointed at them).

workspace_repo produces the canonical two-unit shape the serve-op conformance suite expects: cargo workspace members aaa (depended on by bbb), tagged aaa-v0.1.0 / bbb-v0.1.0, then one feat(aaa) + one fix(bbb) commit — so plan yields a minor bump for aaa and a patch for bbb.
