tarsi-publish — the publish port. One Publisher per forge target; tarsi-serve/drivers iterate tarsi_core::ReleasePlan units in order and dispatch by PublishTarget. All impls are sync; secrets arrive as env-var names or cuora:// refs resolved through token::TokenResolver — values never in config or logs (cuora boundary).

Modules§

token
Publish-token resolution — the seam between config’s secret names (token_env) / refs (token_ref) and the values the forges consume. Values are secret: they are never logged, never placed in error messages, and never written anywhere but the child process environment / Authorization header.
