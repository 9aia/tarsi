tarsi-config — loads tarsi_core::Config through scarab-config’s file discovery: explicit $TARSI_CONFIG → ./tarsi.{yaml,yml,toml} (YAML preferred) → ~/.config/tarsi/. No tarsi-config-* crates — the generic machinery is scarab’s (P-017); this crate is only the wiring.

Release profiles (type: tarsi packs — PL-014 D2) layer under the repo config: a profile is a dir containing a tarsi.* file, discovered via profile (explicit arg → $TARSI_PROFILE → profile = "…" in config). With a profile resolved, loading switches to scarab’s LayeredFileSource: repo tarsi.* > profile tarsi.* > ~/.config/tarsi/ > defaults. Without one, behavior is unchanged (first-match FileSource).
